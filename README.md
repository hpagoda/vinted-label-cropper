# Vinted Label Cropper

[Use the Label Cropper online](https://hpagoda.github.io/vinted-label-cropper/)

**Set up:**

1. Download **[Label-Cropper-4x6.html](https://github.com/hpagoda/vinted-label-cropper/raw/refs/heads/main/Label-Cropper-4x6.html)** and save it somewhere easy on the host, like the Desktop.
2. Right-click it → **Open with → Firefox**. You can bookmark it in Firefox or pin a shortcut.

**Each time you have a label:**

1. Download the label PDF from Vinted.
2. Drag the PDF onto the Label Cropper page, or click the box to pick the file. A preview of the cropped 4×6 label appears.
3. Click **Open label to print**, then press **Ctrl + P**.
4. Set Printer: **Zebra**, Paper size: **4 × 6 in**, Scale: **100%**, Margins: **None**, and headers and footers **off**. Firefox usually remembers these settings after the first time.

If you download several labels at once in a single PDF, it crops each page into its own 4×6 label. It runs entirely on your computer and works without internet; your labels aren’t sent anywhere.
